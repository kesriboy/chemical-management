# 化学品管理系统

面向实验室 / 工厂化学品领用与台账管理的单机应用。纯前端实现，**双击 `index.html` 即可运行**，无需安装、无需联网、无需起服务。

---

## 一、快速开始

双击 `index.html`，用 Chrome / Edge 打开即可。

首次使用建议：**数据管理 → 单位名称** 填写公司全称（会作为导出 Excel 与打印记录表的抬头），然后 **数据管理 → 载入示例数据** 先熟悉功能，再清空录入真实数据。

---

## 二、核心功能

### 1. 化学品档案

13 个字段：编号、名称、CAS 号、类别、危险性、规格/包装、单位、期初库存、库存下限、存放位置、生产厂家、有效期、备注。

- 库存列显示的是**当前库存**（实时计算），低于下限自动标黄预警，负库存标红
- 支持按名称/编号/CAS/厂家搜索，按类别、危险性筛选，可勾选「仅看预警」
- 有领用记录的化学品不允许删除（防止历史记录失去关联）
- 「导出台账」输出 CSV，含期初库存、当前库存、库存下限

### 2. 领用记录

字段：化学品、数量、领用日期、领用人、部门、用途、发放人、状态、备注。

- **单据号自动生成**：`LY + 日期 + 4 位序号`，如 `LY20261022-0001`
- **库存实时联动**：填写数量时下方实时提示「当前库存 → 发放后剩余」，不足时标红
- **退库**：`已退库` 状态的记录表示退料，库存返还
- **编辑与删除自动回冲库存**，任何操作都不会造成账实不符
- 数量为 0 / 负数、缺领用人、缺用途、超库存均会被拦截并提示原因

### 3. 领用记录表（核心输出）

多条件筛选：**日期区间** × **部门** × **化学品** × **危险性**，可自由组合。

输出方式四种：

| 方式       | 说明                                                   |
| -------- | ---------------------------------------------------- |
| 导出 Excel | `.xls` 格式，3 个工作表：领用明细 / 按化学品汇总 / 按部门汇总。带样式、冻结表头、单位抬头 |
| 导出 CSV   | UTF-8 带 BOM，Excel 双击不乱码                              |
| 打印 / PDF | A4 横向，自动带标题、统计摘要、合计行、制表/审核/批准签字栏                     |
| 页面预览     | 表格实时预览，含合计行                                          |

汇总维度可切换：**按化学品 / 按部门 / 按领用人 / 按用途 / 按月份 / 按类别**。

### 4. 数据管理

- 导出 / 导入 JSON 备份（按记录 ID 合并，可跨机器迁移）
- 查看存储统计
- 清空领用记录 / 清空全部数据
- 载入示例数据

## 三、关键设计说明

### 库存是派生值，不是独立字段

领用记录是 append-only 流水账，库存实时计算：

```
当前库存 = 期初库存 + Σ(退库数量) − Σ(发放数量)
```

这样编辑或删除任意一条记录时，库存自动回冲，**不会存在"库存字段与流水对不上"的历史包袱**。清空所有领用记录后，库存自动回到期初库存。

### 单据号只增不复

单号计数器持久化在 `meta.docSeq`。即使记录被删除，已发出的单号也不会被复用 —— 满足审计与追溯要求。

### 不同单位数量不合并计量

瓶 / kg / L 属于不同量纲，汇总时按单位分别统计（如 `15 瓶 / 15 kg`），不强行相加。合计行明确标注「不同单位数量不合并计量」。

## 四、数据存储

数据保存在**本机浏览器的 localStorage**，不上传任何服务器。

- 顶栏「本地存储正常」标识表示写入正常
- 清理浏览器数据 / 换浏览器 / 换电脑会导致数据不可见
- **请定期在「数据管理」导出 JSON 备份**

> 需要多台电脑共享或手机访问时，可将本目录部署到 Render 等静态托管（保持文件结构不变即可）。

## 七、在线访问（GitHub Pages）

本项目为纯静态站点，可直接用 GitHub Pages 托管：

1. 仓库 **Settings → Pages**
2. Source 选择 **Deploy from a branch**，分支选 `main`、目录选 `/ (root)`
3. 等待 1–2 分钟，访问 `https://<用户名>.github.io/<仓库名>/`

> 在线版与本地版功能一致。**注意**：localStorage 按「域名 + 协议」隔离，
> 因此在线版与本地 `file://` 打开时的数据**互不相通**。如需在线使用，
> 请在在线环境中重新录入，或用「数据管理 → 导出 JSON」从本地迁移过去。
